# pay-review-station

一个面向 **Java 后端 / 支付清结算方向** 面试复习的离线知识站。

内容全部是可版本管理的 markdown，构建成**零第三方依赖**的单页站点：双击 `index.html` 即可使用，可整体拷进内网。

---

## 快速开始

```bash
python3 build.py          # 构建（改完 markdown 跑这一条）
python3 build.py --check   # 只校验字段和引用关系，不生成
```

打开 `index.html` 即可。或用 `make serve` 起本地服务（`http://localhost:8787`），localStorage 存进度更稳定。

不需要 npm、不需要装任何包，Python 3 标准库就够。

## 目录结构

```
pay-review-station/
├── content/            内容的唯一来源，只改这里
│   ├── layers/         S1~S6     六层能力模型
│   ├── nodes/          A1~F4     33 个知识点节点
│   ├── cards/          A3-01-xxx 知识卡片（一个知识点一篇）
│   └── scenarios/      S01-xxx   场景题（一道题串多个知识点）
├── theme/              站点模板（index.html / app.js / style.css）
├── build.py            构建器（零依赖）
├── FORMAT.md           内容格式规范 ← 写新内容前必读
├── index.html          构建产物，可直接打开
└── assets/             构建产物（data.js / app.js / style.css）
```

`index.html` 和 `assets/` 是产物，改它们没用，每次构建都会覆盖。

| 视图 | 作用 |
|---|---|
| 总览 | 覆盖率、各层进度、内容缺口清单 |

## 怎么新增知识点 / 场景题

两条路，选一条。

### 方式 A：自己写

1. **建文件**：卡片 → `content/cards/节点id-序号-标题.md`（如 `B5-02-xxx.md`）；场景题 → `content/scenarios/S15-标题.md`
2. **复制 front-matter**（字段定义见 `FORMAT.md` 第 2 节）：

```yaml
---
id: S15
title: "一句话标题，带具体场景"
kind: scenario
nodes: [C6, D4, E1]
primary: C6
direction: "系统设计"
event: "生产故障"
project: "招银云创 / PayBy / shopline 中的真实片段"
level: core
status: draft
created: 2026-11-03
updated: 2026-11-03
---
```

3. **正文九段**，标题原样抄（七段强制 + 两段附加，见 `FORMAT.md` 第 5 节）：

```
## 30 秒简述
## 是什么
## 为什么这么设计
## 不用会怎么样
## 替代方案
## 项目中如何使用
## 常见陷阱
## 三层追问
## 我的口述记录
```

4. **构建**：`python3 build.py`，打开 `index.html` 看效果。

`nodes` 的取值决定它挂在哪个知识点、在图谱上跟谁连线；写多个 id 就会自动连成跨层线。

### 方式 B：把素材丢给 AI 整理（推荐）

**可行，但素材决定成稿质量**——AI 能补结构、补表达、补追问链，补不了你的项目细节。细节缺失时我宁可留 `（待补充）` 标出来，也不会编。

交给我的最小信息：

| 要给什么 | 说明 |
|---|---|
| 题目 | 一句话，如「Redis 热 key 打挂单分片」 |
| 类型 | 知识卡片，还是场景题（一道题串多个知识点） |
| 挂哪些节点 | 不确定就描述场景，我从 33 个节点里挑 |
| 真实项目片段 | 哪个系统、你做了什么、关键流程或数字 |
| 你想被追问的点 | 你答不利索的地方，我往那儿写 |

直接这样说就行：

> 加一道场景题：渠道日限额被打满，正常交易被拒。挂在 C6、D4、E1。
> 项目是 PayBy 的渠道限额，当时用 Redis 计数 + DB 兜底，出过一个问题……

口述也行：把想讲的先录音转文字，或者直接大白话打一段，我来拆成九段。

我会交付：新建的 md 文件 + 跑构建 + 更新覆盖率数字。**不做的两件事**：编造项目细节、代写 `## 我的口述记录`（那是你的复述练习，必须自己填）。

### 改完自检三条

1. `python3 build.py --check` 通过（字段、节点引用、id 重复）
2. 卡片页能打开，九段顺序正确
3. 路线图上对应节点从虚线变实线，图谱上出现新连线

## 内网部署

产物合计约 156 KB，零外部引用（无 CDN、无网络字体、无图片、无运行时请求）。

```
index.html  +  assets/
```

拷进内网任意目录即可。三条注意事项：

1. **进度可能丢**：`file://` 下 localStorage 行为因浏览器而异，建议固定一个浏览器；后续可加导出/导入功能。
2. **不支持 IE11**：用了 `Element.closest()` 和 `Set`，Edge / Chrome / 新版本地浏览器都正常。
3. **安全扫描可能误报**：页面用 `innerHTML` 渲染，数据全部来自本地构建产物，无用户输入、无外部数据源。
