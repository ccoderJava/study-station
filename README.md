# pay-review-station

一个面向 **Java 后端 / 支付清结算方向** 面试复习的离线知识站。

内容全部是可版本管理的 markdown，构建成**零第三方依赖**的单页站点：双击 `index.html` 即可使用，可整体拷进内网。

---

## 快速开始

```bash
python3 build.py          # 构建（改完 markdown 跑这一条）
python3 build.py --check   # 只校验字段和引用关系，不生成
```

打开 `index.html` 即可。或用 `make serve` 起本地服务（`http://localhost:8787`），localStorage 存进度更稳定。

不需要 npm、不需要装任何包，Python 3 标准库就够。

---

## 目录结构

```
pay-review-station/
├── content/            内容的唯一来源，只改这里
│   ├── layers/         S1~S6     六层能力模型
│   ├── nodes/          A1~F4     33 个知识点节点
│   ├── cards/          A3-01-xxx 知识卡片（一个知识点一篇）
│   └── scenarios/      S01-xxx   场景题（一道题串多个知识点）
├── theme/              站点模板（index.html / app.js / style.css）
├── build.py            构建器（零依赖）
├── FORMAT.md           内容格式规范 ← 写新内容前必读
├── index.html          构建产物，可直接打开
└── assets/             构建产物（data.js / app.js / style.css）
```

`index.html` 和 `assets/` 是产物，改它们没用，每次构建都会覆盖。

## 站点包含

| 视图 | 作用 |
|---|---|
| 总览 | 覆盖率、各层进度、内容缺口清单 |
| 路线图 | 六层能力模型，节点显示「N 卡片 · N 场景题」，空白节点为虚线 |
| 知识图谱 | 节点按层分泳道；场景题连出跨层线，看出哪些知识点会组合出现 |
| 内容列表 | 按技术方向分组，可按 event 筛选 |
| 卡片阅读 | 七段式正文 + 元信息栏 + 掌握度标记（未学 / 学习中 / 能讲） |
| 搜索 | 全站搜标题、关键词、正文 |

学习进度存在浏览器 localStorage，不上传、不联网。

## 内容怎么写

看 `FORMAT.md`。一个要点：每篇卡片固定九段，其中 `## 项目里怎么用（陈聪）` 必须写真实项目细节，否则面试时讲不出来。

## 内网部署

产物合计约 156 KB，零外部引用（无 CDN、无网络字体、无图片、无运行时请求）。

```
index.html  +  assets/
```

拷进内网任意目录即可。三条注意事项：

1. **进度可能丢**：`file://` 下 localStorage 行为因浏览器而异，建议固定一个浏览器；后续可加导出/导入功能。
2. **不支持 IE11**：用了 `Element.closest()` 和 `Set`，Edge / Chrome / 新版本地浏览器都正常。
3. **安全扫描可能误报**：页面用 `innerHTML` 渲染，数据全部来自本地构建产物，无用户输入、无外部数据源。
