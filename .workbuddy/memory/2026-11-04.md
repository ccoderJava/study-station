- B1-01 改名《索引是怎么工作的：B+ 树、回表、覆盖与索引下推》，主线定为「一条查询的三段路」：B+ 树结构 → 聚簇/二级分工 → 第一棵树定位 → 第二棵树回表 → 覆盖在 ① 截断 → ICP 在 ①② 之间截断 → 最左前缀其实由字典序决定。补了页内 slot、三层 2100 万行的算法、MRR、skip scan 的边界。
- B1-02 改名《索引失效与优化顺序》，把失效清单收成**三关归因**：有序性 / 最左前缀 / 成本。核心判断是「失效不是布尔值，是用了几列、扫多少行、回几次表」。新增 `key_len` 反推用了几列（varchar(32) utf8mb4 = 130，+date = 133，+tinyint = 134），这是比背口诀硬的判断手段。
- 优化顺序拆两级概念，别混：
  - **治理顺序**（四级阶梯）：第 0 级先排除锁/延迟/网络 → 改 SQL 形态（零成本） → 调索引（写放大） → 改表结构（迁移） → 改架构（不可逆）。升级信号写死在每级卡片里。
  - **联合索引列序**（五条规则）：等值在前、范围在后、排序列跟等值列、高频返回列做覆盖、3~5 列。纠正一个高频错答：**等值列之间顺序无所谓**，有所谓的是范围列和排序列的位置。
- 四张图（900 宽、沿用蓝/绿/红/橙语言）：`index-query-path.svg`（两棵树 + 三条截断路径）、`index-icp.svg`（无 ICP 1000 次回表 vs 有 ICP 20 次，强调扫描行数不变）、`index-fail-check.svg`（三关三列）、`sql-optimize-order.svg`（四级阶梯 + 升级信号）。

## 图谱节点改成名称标签

- 层色仍用 `LAYER_HUE`，但填充改成**不透明混合色** `tint(color, t)`（deg≥3 → 20%，≥1 → 14%，0 → 9%）——半透明底会让底下的连线透上来压字。

  1. **去重叠换算法**：原来按圆半径推开，胶囊宽高比 4:1，必须改成矩形分离（算 ox/oy，沿重叠小的轴推），不然标签横向压成一团。
  2. **连线裁剪两级**：先用 `clipPt()` 把端点停在标签边框（射线与矩形求交），再用 `segRect()`（Liang-Barsky）把线段被中间标签挡住的部分切掉，每段两端再缩 1.8px 防相切误判。75 条边会被切成 ~110 段。
  3. **参数重调**：画布 960×700、R=218、rep 13500、rest 122、spring 0.046、gap 12、去重叠 220 轮。调字号没用——布局宽度正比于字号，缩放比反比，最终显示字号不变，只能降密度。

- 窄屏：≤1120px 时 `.gwrap svg` 固定 1040px 内部横滚（原来 100% 宽会把 11.5px 压到 7px）；≤920px 用 900px。

  - 悬停提示从「S02 · 关联 5 个知识点」改成「场景题 · 串起 5 个知识点」，编号彻底消失。
- **布局分区**：场景题集中在中心三圈（`perRing = [4,7,9]`，`rings = [78,140,198]`），知识点按层锚在外环 `R=290`；画布 1080×750。
  - 关键补丁：去重叠是「对半推开」，整团会一路漂到角落（Spring 那组就飘到过右下角）。现在 `separate(180)` 之后**按层把质心拉回锚点（×0.55）、场景题质心拉回中心（×0.35）**，再 `separate(160)` 收尾。
- **悬停闪屏的根因和改法**（这是重点）：
  - 原来 `mouseenter` 挂在每个节点上，每次触发都遍历 53 个节点 + 四百多条线段写 inline `style.opacity`/`setAttribute('stroke')`；跨标签时先 `mouseleave` 清空再 `mouseenter` 点亮，中间必有一帧全灭 → 视觉上就是闪。
  - 改成**委托到 svg 的 `pointermove`** + `closest('.gn')`；110ms 预热（快速划过不触发）、220ms 延迟清除（跨标签直接换目标，不经过全灭）。
  - 高亮状态交给 CSS：`#gsvg[data-hi] .gn{opacity:.13}` + 少量 `.on` 类（只碰当前节点、邻居和相连线段），不再全量写 style。
  - 提示框改 `transform: translate3d()` 位移（原来每次 mousemove 改 left/top 触发布局），并钳在容器内、上移 20px 不压标签。
  - 拖动平移用 rAF 合并，`pointerdown` 时清高亮。
- 验证（CDP）：编号残留 0 / 重叠 0 / 贴边 0 / 穿标签 0（重新布局后同样 0）；50ms 内不高亮、300ms 后高亮且提示无编号、跨标签直接切换、移出 120ms 仍保留 420ms 后清除。提交 `20c83d8`。
