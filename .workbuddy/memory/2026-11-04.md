## 侧栏支持拖拽调宽

- 用户要求：左侧菜单（侧栏）也要能像右侧目录那样拖动调宽。
- 结构：`theme/index.html` 的 `.layout` 里 aside 与 main 之间插入 `<div class="side-resize" id="sideResize">`，热区 9px，`::before` 画 1px 线（hover 变蓝、拖动 2px 主色）。
- CSS：aside 去掉 `border-right`（线由 resizer 承担），加 `min-width:180px;max-width:460px`；`aside.resizing` 淡蓝底 + 内阴影（#f4f7fd）；≤920px 时 resizer 与 aside 一起隐藏。
- JS：`bindSideResize()` 用 Pointer Events + `setPointerCapture`，`apply(w)` 同时写 `flexBasis` 与 `width`；范围 180–460，另有 `sideMax() = min(460, innerWidth*0.42)` 软上限，避免窄屏把正文压没；宽度存 `review-side-w-v1`，双击复位 264；window resize 时按存档重新夹紧（不改存储，放大窗口可还原）。
- 验证（CDP）：264 → 384 → clamp 180 → clamp 460，切图谱/卡片/刷新均保持 324；1280 拖到最大正文 756 无溢出；缩到 1000 自动夹到 420，860 时 aside 与 resizer 同时 display:none；960 窗口 + 400 侧栏的图谱页无横向溢出。
- 注意：`renderSide()` 会重建 aside 的 innerHTML，但宽度写在 aside 自身的 inline style 上，不受影响。
